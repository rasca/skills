Validators

genlayernode plugin

Interactive wizard to set up a GenLayer validator node on Linux. 11-step guided install with zero-downtime updates.

validator-manage dev

Manage validators across testnets. Join, fund, set identity, list, and organize validators per network and owner.

Development

write-contract plugin

Write production-quality intelligent contracts. Equivalence principles, error classification, storage rules, LLM resilience.

genvm-lint plugin

Validate contracts for safety, correctness, and SDK compliance. AST checks, semantic validation, ABI extraction.

genlayer-cli plugin

Deploy, interact with, and debug intelligent contracts. Transaction receipts, account management, network config.

Testing

direct-tests plugin

Fast in-memory tests (~30ms). No server, no Docker. Mock web requests and LLM responses. Full VMContext cheatcodes.

integration-tests plugin

Full consensus testing against GenLayer environments. GLSim, Studio, or testnet with real leader + validator agreement.

How it works

01
Add the marketplace

Register the GenLayer skills marketplace in your Claude Code session. One-time setup.

/plugin marketplace add genlayerlabs/claude-code-skills
02
Install a plugin

Choose which plugin to install. Each plugin bundles related skills together.

/plugin install genlayer-dev@genlayerlabs
03
Just ask Claude

Skills activate automatically based on context. Ask Claude to write a contract, set up a node, or run tests.
